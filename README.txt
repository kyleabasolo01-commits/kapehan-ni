KAPEHAN NI KALOY - COFFEE SHOP MANAGEMENT SYSTEM

SETUP
1. Extract the ZIP file.
2. Open the extracted folder in VS Code.
3. Open Terminal > New Terminal.
4. Run: npm.cmd install
5. Run: npm.cmd run dev
6. Open http://localhost:3000 (do not use VS Code Live Preview).

Node.js 20+ is recommended. SQLite creates database/coffeshop.db automatically.
Nine default coffee products are seeded at ₱149 each, with initial stock 0.

categories, in-store orders, notifications, settings, inventory/sales summary and printing.
